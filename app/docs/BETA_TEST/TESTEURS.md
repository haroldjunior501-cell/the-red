# Guide testeur — GOALYA beta

Merci de tester GOALYA. Cette version est une **beta** : quelques écrans affichent encore « bientôt disponible ».

## Installation

1. Installe le build que l’équipe t’a envoyé (TestFlight iOS ou APK Android).  
2. **N’utilise pas Expo Go** pour ce test.  
3. Ouvre l’app et accepte les permissions si demandées.

## Compte

- Crée un compte **email** ou connecte-toi avec **Google** (build officiel).  
4. Choisis **ton pays** dans le profil (important pour Tableau et Hub).

## Parcours à tester (45 min)

| # | Écran | À faire | OK ? |
|---|--------|---------|------|
| 1 | Connexion | Inscription ou Google | ☐ |
| 2 | Accueil | Voir le prochain match, ouvrir le détail | ☐ |
| 3 | Pronos | Pronostic sur un match de groupe | ☐ |
| 4 | Pronos | Fermer l’app, rouvrir → prono toujours là | ☐ |
| 5 | Tableau | Groupes + élimination, choisir un vainqueur | ☐ |
| 6 | Tableau | Valider le tableau (si bouton disponible) | ☐ |
| 7 | Hub | Envoyer un message sur le match | ☐ |
| 8 | Live | Parcourir matchs à venir / live | ☐ |
| 9 | Fantasy | Composer une équipe (11 joueurs) et sauvegarder | ☐ |
| 10 | Fantasy | Conversion FP (si proposée) | ☐ |
| 11 | Map | Ouvrir la carte, naviguer | ☐ |
| 12 | Session | Déconnexion puis reconnexion | ☐ |

## Signaler un bug

Indique toujours :

- **Modèle** (ex. iPhone 15, Samsung S24)  
- **Étape** (ex. « Tableau → Valider »)  
- **Résultat** (crash, écran vide, message d’erreur)  
- **Capture d’écran** si possible  

Envoie au canal indiqué par l’organisateur (Discord / mail support).

## Limites connues (normal en beta)

- Stories / certains « moments forts » peuvent être vides.  
- Blessés parfois non renseignés.  
- Arena Simulator : interface testable ; duels live complets autour des vrais matchs CdM.  
- Paiement carte : seulement si l’organisateur a le serveur allumé pendant le test.
